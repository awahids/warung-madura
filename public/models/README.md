# Model GLB (opsional)

Taruh model hasil Meshy/Blender di sini untuk menggantikan prop prosedural di halaman `#/props`:

`galon.glb`, `gas.glb`, `toples.glb`, `bensin.glb`, `rakBensin.glb`, `kardus.glb`, `beras.glb`

Skala dan posisi disesuaikan otomatis (tinggi target & alas di y=0). Halaman otomatis memakai file yang ada.
